# Memory review

Use at the start of a session, or when the user refers to earlier work
without saying which.

## Procedure

1. Call `fireice_recall` with no query to list durable facts, or with a
   topic to find related past sessions.

2. Summarise in two parts:
   - what Fire-Ice knows about their work
   - what they were last investigating, with dates

3. Offer the obvious next step. If they were tracking a hypothesis, ask
   whether to re-check it against the library.

## Housekeeping

If a stored fact looks stale or wrong, say so and offer to remove it.
Memory that is never pruned becomes noise, and the user should be the one
who decides what stays.
